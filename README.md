# Developer Task Tracker App

An interactive task tracking web application built with HTML5, CSS3, and vanilla JavaScript demonstrating dynamic DOM manipulation, event delegation, filtering, and persistent browser state storage (`localStorage`).

## Core Concepts Covered
* **DOM Manipulation**: Creating, updating, and removing HTML elements dynamically using JavaScript.
* **Event Handling**: Form submissions, checkbox toggles, filter switches, and item deletions.
* **Browser Persistence**: Utilizing `localStorage` to save user state across sessions.
* **Array Filtering**: Executing JavaScript array methods (`filter`, `map`, `forEach`) for state updates.

## How to View Locally
Open `index.html` in any web browser.
